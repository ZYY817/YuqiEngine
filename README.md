国内高集成度的 Windows 游戏性能优化工具，由独立开发者打造。

## 功能特性

- 🎮 **系统优化工具集** — 按模块检查并调整与游戏体验相关的系统设置
- 🔄 **系统还原/备份** — 优化前自动备份，随时一键还原，安全无忧
- ⚡ **电源方案管理** — 可视化电源方案编辑器，内置高性能预设
- 🎯 **游戏进程优先级管理** — 自动为游戏进程分配最优 CPU 亲和性和优先级
- 🖥️ **硬件信息检测** — 实时系统监控，CPU/GPU/内存/磁盘全面展示
- 🛠️ **系统修复中心** — 常见游戏问题一键修复（网络、音频、存储等）
- 🌐 **中英双语支持** — 完整的中文/英文界面切换
- 🎨 **深色界面** — 聚焦低干扰的桌面使用体验

## 下载安装

1. 前往 [Releases 页面](https://github.com/ZYY817/YuqiEngine/releases) 下载最新版本
2. 解压 ZIP 到任意目录
3. 运行 `YuqiEngine.exe`

> 部分优化功能需要以管理员身份运行。

## 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11（64 位） |
| 运行时 | 已内置，无需额外安装 |
| 内存 | 2 GB 以上（推荐 4 GB） |
| 磁盘 | 500 MB 可用空间 |

## 技术栈

- .NET 8 + WPF
- 自包含部署（Self-Contained），无需安装 .NET 运行时
- 模块化架构，支持插件扩展
