# SAFETY — 红线与授权

## 一、永远禁止

不做、不教、不推荐，用户点名也不执行：

1. 关闭/卸载 Defender、杀软实时防护，或给游戏目录加杀软排除项。
2. 绕过/禁用反作弊（ACE/EAC/BattlEye/Vanguard）或修改反作弊相关文件。
3. 关闭 UAC、Windows 防火墙、Windows Update。
4. 修改网络栈注册表：Nagle、TCP 参数、QoS、Winsock reset、NetworkThrottlingIndex、关 RSS、破坏 LSP。
5. 关闭 HPET、平台时钟、页面文件、内存压缩。
6. 删除系统目录：System32、WinSxS、DriverStore、Installer、Prefetch。
7. 内存清理器 / EmptyStandbyList / RAMMap Standby 清空、注册表清理/整理、第三方"一键清理/优化包"。
8. 刷写固件：BIOS / VBIOS / SPD。
   - 注意：进 BIOS/UEFI **改设置项**（XMP、ReBAR、风扇曲线、Above 4G）不算刷 BIOS，属于用户自行操作范围。
9. 分区格式化、动用户存档、远程代操他人电脑。
10. Win32PrioritySeparation 修改、ISLC/计时器分辨率工具、各类"游戏注册表优化包"——蛇油，不做。

## 二、需证据 + 用户手动（模型不代执行，只给说明与恢复方法）

- **SysMain / Superfetch**：仅 HDD + 磁盘 100% + 资源监视器显示 SysMain 高占用时，指导用户在 `services.msc` 手动禁用并给出恢复命令；SSD 通常无感或略负。
- **Windows Search 降负**：先切"经典"模式 + 排除目录；停 WSearch 为末选，必须说明搜索会变慢。
- **DDU 驱动擦除**：仅驱动损坏/反复异常时，用户书面点名后自行在安全模式执行；常规驱动更新不推 DDU，优先官方安装器"清洁安装"。
- **服务层**：仅可禁用用户点名的第三方服务；`msconfig` 须勾"隐藏所有 Microsoft 服务"；微软服务一律不动。
- **VBS / HVCI / 安全启动 / TPM**：用户书面点名 + 检索反作弊官方不要求 + 完整找回路径；检索失败 = 禁止关闭。

## 三、授权规则

1. 清单对用户用本轮连续编号 1,2,3…；ITEMS 的 A1/J3 仅内部索引，不出现在用户话术里。
2. **UI 点击类**（Windows 设置、显卡面板、游戏菜单）：口头确认即可（"做 1、3"/"都做"/"按你说的来"）。
3. **命令/注册表/服务/网络/驱动/清理类**：用户用编号点名后，默认打包成脚本由用户**右键"以管理员身份运行"**；若终端已是管理员且用户要求直接跑，可逐条执行。口头"好/嗯"不算命令项授权。
4. **不可逆/高风险项**（I4 清空回收站、I5 删 Windows.old、I7 卸载软件、K1 驱动回退、K2 进 BIOS 开 XMP、K4 拆机、全部 L 类）：全选/"都做"不涵盖，必须逐项点名 + 用户复述风险（"我知道删了找不回来"）。
5. 授权仅对当轮清单有效；新一轮重新编号、重新选。
6. 执行前备份：注册表 `.reg` 导出、电源 `powercfg /export`、优先确认存在还原点（无则 `Checkpoint-Computer` 或至少 .reg 备份）；备份与每轮改动记录统一放工作目录 `tuning\`（备份 + `log.md`）。
7. 执行后立即回读；回滚后必须复测确认指标回到基线，否则回滚未闭环。
8. 编辑游戏配置文件：先复制原文件备份；只改显示/性能键，不动反作弊、可执行文件、存档。

## 四、高阶/风险项处理

- `L` 类（VBS/HVCI/MSI Mode/TdrDelay/持久化亲和等）只做说明，不主动执行。
- 用户书面点名某一项后，再单独讨论风险、备份、复测。
- 检索反作弊是否要求安全项；检索失败 = 禁止关闭。

## 五、出问题优先级

1. 回滚刚改的一项。
2. 网络 → 设备管理器启用网卡、改回自动 DNS。
3. 电源 → `powercfg /setactive <原GUID>`。
4. 系统还原点。
5. 停止叠加优化。
