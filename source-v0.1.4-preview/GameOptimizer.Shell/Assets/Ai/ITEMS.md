# ITEMS — 优化项清单

说明：
- **效果** 是常见收益预期，最终以这台机器实测为准。
- **执行** 是常见操作路径；执行前必须在本机重新定位真实键/菜单/GUID。
- **UI 项** 是用户自己点；**命令项** 是模型打包成脚本、由用户右键"以管理员身份运行"（或管理员终端内执行）的 PowerShell/命令。
- **风险色标**（给用户的清单里标注）：🟢 安全可逆 | 🟡 有代价/有条件（副作用写明）| 🔴 高阶/不可逆（L 类、不可逆清理、拆机/BIOS 类，逐项点名）。
- **对用户的编号**用本轮连续 1,2,3…；本文件的 A1/J3 是内部索引，不出现在用户话术里。
- 没有效果就回滚，有效果才保留。

## A 电源 / 调度

### A1 电源计划改为高性能
- 效果：中 / 依场景（现代 CPU 上平衡计划差距常接近零，主要价值是稳定性；旧 CPU / 当前为省电计划时才明显）
- 作用：避免 CPU/GPU 在平衡模式下降频，提升帧时间稳定性。
- 适用：台式机或插电笔记本；当前为平衡/节能。
- 风险：笔记本发热、耗电增加。
- 撤销：改回原 GUID 并 `powercfg /setactive <原GUID>`。
- 执行：
  - `powercfg /list` 找到“高性能” GUID；
  - `powercfg /setactive <GUID>`；
  - Win11 再进 设置 → 系统 → 电源 → 最佳性能。

### A2 启用卓越性能计划（Ultimate Performance）
- 效果：低 / 依场景（现代 CPU 上与高性能计划基本无差异）
- 作用：比高性能更激进地禁止 CPU idle 降频。
- 适用：高端台式机；CPU 限游戏；散热足够；多数场景等同 A1，不优先。
- 风险：发热、耗电明显增加。
- 撤销：改回原 GUID。
- 执行：
  - `powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61`；
  - 拿到新 GUID 后 `powercfg /setactive <GUID>`。

### A3 Win11 电源模式改为最佳性能
- 效果：中
- 作用：系统层面的电源滑块，叠在电源计划之上。
- 适用：Win11 笔记本/台式。
- 风险：基本无。
- 撤销：设置里改回平衡/推荐。
- 执行：设置 → 系统 → 电源 → 最佳性能。

### A4 关闭 PCI Express 链接状态电源管理
- 效果：中（DPC/延迟尖峰场景）
- 作用：防止 PCIe 设备进入低功耗状态导致延迟尖峰。
- 适用：DPC/爆音/延迟尖峰主诉。
- 风险：待机功耗略高。
- 备份：
  ```powershell
  $null = (powercfg /getactivescheme) -match '([0-9a-fA-F]{8}-(?:[0-9a-fA-F]{4}-){3}[0-9a-fA-F]{12})'
  $origGuid = $matches[1]
  $origGuid | Set-Content "$env:USERPROFILE\Desktop\powerplan_guid.txt"
  powercfg /export "$env:USERPROFILE\Desktop\powerplan_backup.pow" $origGuid
  ```
- 撤销：
  ```powershell
  $origGuid = Get-Content "$env:USERPROFILE\Desktop\powerplan_guid.txt"
  powercfg /import "$env:USERPROFILE\Desktop\powerplan_backup.pow" $origGuid
  powercfg /setactive $origGuid
  ```
- 执行：控制面板 → 电源选项 → 更改计划设置 → 更改高级电源设置 → PCI Express → 链接状态电源管理 → 关闭。

### A5 关闭 USB 选择性暂停
- 效果：中（输入延迟 / DPC）
- 作用：防止 USB 设备睡眠导致输入延迟或音频爆音。
- 适用：跟枪/鼠标/音频爆音。
- 风险：待机功耗略高。
- 备份：
  ```powershell
  $null = (powercfg /getactivescheme) -match '([0-9a-fA-F]{8}-(?:[0-9a-fA-F]{4}-){3}[0-9a-fA-F]{12})'
  $origGuid = $matches[1]
  $origGuid | Set-Content "$env:USERPROFILE\Desktop\powerplan_guid.txt"
  powercfg /export "$env:USERPROFILE\Desktop\powerplan_backup.pow" $origGuid
  ```
- 撤销：
  ```powershell
  $origGuid = Get-Content "$env:USERPROFILE\Desktop\powerplan_guid.txt"
  powercfg /import "$env:USERPROFILE\Desktop\powerplan_backup.pow" $origGuid
  powercfg /setactive $origGuid
  ```
- 执行：控制面板 → 电源选项 → 更改计划设置 → 更改高级电源设置 → USB 设置 → USB 选择性暂停设置 → 已禁用。

### A6 关闭快速启动（Hybrid Boot）
- 效果：低 / 依场景
- 作用：避免部分驱动/服务因快速启动未完全重置导致异常；同时可释放 hiberfil.sys 占用的数 GB 空间。
- 适用：睡眠/唤醒后卡顿、启动项异常、C 盘紧张。
- **禁止**：不要对“开机慢”主诉推荐本项——冷启动只会更慢。
- 风险：冷启动速度变慢；同时会彻底关闭休眠功能（无 hibernate，只剩 sleep/shutdown）。
- 撤销：`powercfg /h on`（管理员）。
- 执行：`powercfg /h off`（管理员）。

### A7 启用 OEM 性能模式（笔记本）
- 效果：中 / 高
- 作用：厂商预设的散热/功耗策略，通常比 Windows 计划更激进。
- 适用：有 Lenovo Vantage / Dell Power Manager / Armoury Crate / MSI Center 等。
- 风险：风扇更吵、发热。
- 撤销：改回默认/安静/平衡模式。
- 执行：在 OEM 控制软件内切换。

## B Windows 游戏功能

### B1 开启游戏模式
- 效果：中 / 低
- 作用：游戏时抑制 Windows Update、后台通知干扰。
- 适用：Win10/11；后台多任务。
- 风险：部分老游戏可能冲突。
- 撤销：设置里关闭。
- 执行：设置 → 游戏 → 游戏模式 → 开。

### B2 开启硬件加速 GPU 调度（HAGS）
- 效果：依场景（现代卡通常 ±几个百分点；也是帧生成的前置条件）
- 作用：让 GPU 自己管理调度队列，降低 CPU 开销和延迟。
- 适用：RTX 30+/RX 6000+/Arc；DX12 游戏。
- 风险：老卡可能更卡；改完要重启。
- 撤销：设置里关闭，重启。
- 执行：设置 → 系统 → 显示 → 图形 → 更改默认图形设置 → 硬件加速 GPU 调度 → 开。
- 注意：脚本读 `HKLM\SYSTEM\CurrentControlSet\Control\GraphicsDrivers\HwSchMode` 判断；若没读到但 UI 显示已开，以 UI 为准，不要再写注册表。

### B3 关闭 Xbox Game Bar
- 效果：中
- 作用：减少全局覆盖层和后台服务占用。
- 适用：不用 Win+G 截图/录屏。
- 风险：无法 Win+G 调用。
- **例外**：AMD 双 CCD X3D（如 7950X3D）依赖 Game Bar 识别游戏并停靠 CCD，关闭可能导致调度变差，这类 CPU 建议保留。
- 撤销：设置里打开。
- 执行：设置 → 游戏 → Xbox Game Bar → 关。

### B4 关闭后台捕获 / Game DVR
- 效果：中
- 作用：停止“在玩时录制”等后台写入。
- 适用：低配机/不需要录屏。
- 风险：无后台回放。
- 撤销：设置里打开，或改回注册表原值（改前 `.reg` 备份）。
- 执行：设置 → 游戏 → 捕获 → 后台录制 → 关。

### B5 设置游戏使用高性能 GPU
- 效果：高（双显卡笔记本）
- 作用：让指定游戏走独显而不是核显。
- 适用：笔记本有核显+独显。
- 风险：基本无。
- 撤销：设置里删除指定。
- 执行：设置 → 系统 → 显示 → 显示卡 → 浏览 → 选择游戏 exe → 高性能。

### B6 开启可变刷新率（VRR）
- 效果：依场景
- 作用：配合 G-Sync/FreeSync 减少撕裂和卡顿。
- 适用：显示器支持 VRR。
- 风险：基本无。
- 撤销：设置里关闭。
- 执行：设置 → 系统 → 显示 → 图形 → 可变刷新率 → 开。

### B7 禁用全屏优化（按游戏兼容性）
- 效果：依场景
- 作用：仅 DX9/老引擎或有明确症状（切屏黑屏、帧时间异常）时可试。
- 适用：特定老游戏异常；Win11 现代游戏通常保留默认更好。
- 风险：可能更卡或画面异常。
- 撤销：取消勾选。
- 执行：游戏 exe → 右键属性 → 兼容性 → 勾选“禁用全屏优化”。

### B8 开启 Windows 11 窗口化游戏优化
- 效果：中
- 作用：让无边框/窗口化游戏拿到近似独占的 flip model 延迟；与 J6 联动。
- 适用：Win11；习惯无边框的用户。
- 风险：极少，个别老游戏异常。
- 撤销：设置 → 系统 → 显示 → 图形 → 窗口化游戏优化 → 关。
- 执行：设置 → 系统 → 显示 → 图形 → 窗口化游戏优化 → 开。

## C 显示 / 输入

### C1 刷新率设为最高
- 效果：高（顺滑度 / 跟手）
- 作用：让显示器跑满刷新率。
- 适用：所有显示器。
- 风险：基本无。
- 撤销：改回原 Hz。
- 执行：设置 → 系统 → 显示 → 高级显示 → 选择最高刷新率。

### C2 禁用鼠标加速
- 效果：中（跟枪手感）
- 作用：鼠标移动距离与屏幕距离一致，竞技更跟手。
- 适用：FPS 竞技玩家。
- 风险：桌面指针会变快，需要适应。
- 撤销：重新勾选“提高指针精确度”。
- 执行：`Win+R` 输入 `main.cpl` → 指针选项 → 取消“提高指针精确度”。

### C3 关闭指针轨迹 / 贴靠
- 效果：低
- 作用：减少一点系统渲染。
- 适用：低配机。
- 风险：基本无。
- 撤销：设置里打开。
- 执行：`main.cpl` → 指针选项 → 取消“显示指针轨迹”；设置 → 辅助功能 → 鼠标 → 关闭“贴靠”。

### C4 音频采样率统一为 48 kHz
- 效果：依场景
- 作用：避免不同采样率转换导致爆音/延迟。
- 适用：爆音、DPC 高。
- 风险：某些设备不兼容。
- 撤销：改回默认格式。
- 执行：声音设置 → 更多声音设置 → 播放设备 → 高级 → 默认格式 → 48000 Hz。

### C5 关闭音频增强
- 效果：依场景
- 作用：减少音频处理延迟。
- 适用：爆音/延迟尖峰。
- 风险：音效变平。
- 撤销：重新打开。
- 执行：声音设置 → 更多声音设置 → 播放设备 → 增强 → 禁用所有增强。

### C6 降低鼠标回报率（4K/8K Hz → 1000/2000 Hz）
- 效果：依场景（低端 CPU / 部分游戏高回报率会造成帧时间毛刺）
- 作用：减少高回报率鼠标产生的中断开销。
- 适用：鼠标支持 4K/8K Hz 且出现不明原因毛刺、卡顿。
- 风险：瞄准手感略变。
- 撤销：改回更高回报率。
- 执行：鼠标驱动 / 配置软件 → 回报率 → 1000 Hz 或 2000 Hz。

## D NVIDIA 控制面板

### D1 电源管理模式 = 最高性能优先
- 效果：中
- 作用：防止 GPU 降频，稳定帧时间。
- 适用：NVIDIA 独显。
- 风险：待机功耗/发热略高。
- 撤销：改回“自适应”或“正常”。
- 执行：桌面右键 → NVIDIA 控制面板 / NVIDIA App → 管理 3D 设置 → 电源管理模式 → 最高性能优先。
- 注意：脚本无法读取 NVIDIA 面板状态。如果用户说已经设置过，直接跳过，不要重复改。

### D2 低延迟模式 = 开 / 超高
- 效果：中（仅 DX9/DX11 且游戏无 Reflex）
- 作用：减少渲染队列延迟。
- 适用：竞技游戏，无 Reflex 支持；DX12/Vulkan 由引擎队列控制，本项无效。
- 风险：“超高”会强制 cap，可能限制帧率；不要与游戏内 Reflex 叠加。
- 撤销：改回关。
- 执行：NVIDIA 控制面板 → 管理 3D 设置 → 低延迟模式。

### D3 线程优化 = 自动（默认）
- 效果：低（驱动默认 Auto 已是最优，手动“开”几乎无差异）
- 作用：多线程处理渲染。
- 适用：多核 CPU；通常无需改动。
- 风险：基本无。
- 撤销：改回自动。
- 执行：NVIDIA 控制面板 → 管理 3D 设置 → 线程优化 → 自动。

### D4 纹理过滤 - 质量 = 高性能
- 效果：低（现代卡几乎无变化）
- 作用：牺牲一点画质换轻微性能。
- 适用：显存紧张/低配。
- 风险：画面变糙。
- 撤销：改回质量。
- 执行：NVIDIA 控制面板 → 管理 3D 设置 → 纹理过滤 - 质量 → 高性能。

### D5 垂直同步 = 开（配合 G-Sync）
- 效果：依场景
- 作用：配合 G-Sync 消除撕裂，帧时间更稳。
- 适用：有 G-Sync/FreeSync 屏，游戏内 V-Sync 关。
- 风险：可能增加一点延迟。
- 撤销：改回关。
- 执行：NVIDIA 控制面板 → 管理 3D 设置 → 垂直同步 → 开。

### D6 帧率上限 = 刷新率 - 3~5
- 效果：中（G-Sync/FreeSync 场景）
- 作用：让帧率稳定在 VRR 范围内，减少撕裂和卡顿。
- 适用：开了 G-Sync/FreeSync。
- 风险：浪费一点性能上限。
- 撤销：改回无限制。
- 执行：NVIDIA 控制面板 → 管理 3D 设置 → 最大帧速率 → 设为刷新率 - 3~5。

### D7 保持着色器缓存开启
- 效果：中
- 作用：减少游戏内重新编译卡顿。
- 适用：默认保持开启即可。
- 风险：不要频繁清；清理后首次更卡。
- 撤销：重新打开。
- 执行：NVIDIA 控制面板 → 管理 3D 设置 → 着色器缓存大小 → 开 / 默认。

### D8 定向清理 NVIDIA 着色器缓存
- 效果：依场景
- 作用：驱动升级后持续卡顿时可排除缓存损坏。
- 适用：升级驱动后游戏异常。
- 风险：首次进游戏重编译更卡。
- 撤销：无；重新进游戏会自动重建。
- 执行（关闭游戏后，仅删文件保留目录；命令项）：
  ```powershell
  $paths = @("$env:LOCALAPPDATA\NVIDIA\DXCache", "$env:LOCALAPPDATA\NVIDIA\GLCache", "$env:LOCALAPPDATA\NVIDIA\ComputeCache")
  foreach ($p in $paths) { if (Test-Path $p) { Get-ChildItem $p -File -Recurse -ErrorAction SilentlyContinue | Remove-Item -Force -ErrorAction SilentlyContinue } }
  ```

### D9 优先使用“程序设置”而非全局，可用 NVIDIA App DLSS Override
- 效果：中
- 作用：只让指定游戏吃高性能/低延迟，不拉高待机功耗；NVIDIA App 可强制更新 DLSS 模型/超分预设。
- 适用：所有 NVIDIA 用户，尤其笔记本/多游戏。
- 风险：全局设置被覆盖后需逐游戏确认。
- 撤销：程序设置页签里点“恢复”。
- 执行：NVIDIA 控制面板 → 管理 3D 设置 → 程序设置 → 选游戏 exe 逐项设置；NVIDIA App → 图形 → 每游戏设置 → DLSS Override。

### D10 启用 G-Sync / 兼容模式本体
- 效果：中（有 VRR 显示器时）
- 作用：让帧率在可变刷新范围内平滑，减少撕裂和卡顿。
- 适用：G-Sync / G-Sync Compatible 显示器 + DP 1.2+ / HDMI 2.0+。
- 风险：少数游戏闪屏，可改“仅全屏”。
- 撤销：NVIDIA 控制面板 → 设置 G-Sync → 取消启用。
- 执行：NVIDIA 控制面板 → 设置 G-Sync → 启用（窗口化和全屏）。

## E AMD / Intel 控制面板

**注意**：本节按“渲染 GPU 是 AMD/Intel”适用；笔记本混合输出时内屏由核显驱动，E5/E7 等部分项对核显输出路径仍有效，不要整组跳过。

### E1 等待垂直刷新 = 除非应用程序指定（AMD）
- 效果：中
- 作用：让游戏内 V-Sync 控制，配合 FreeSync。
- 适用：AMD 独显，有 FreeSync。
- 风险：可能撕裂。
- 撤销：改回“始终开启”。
- 执行：AMD Software: Adrenalin → 图形 → 等待垂直刷新 → 除非应用程序指定。

### E2 Radeon Anti-Lag / Anti-Lag+（AMD）
- 效果：中（竞技游戏）
- 作用：降低输入到显示的延迟。
- 适用：竞技 FPS。
- 风险：Anti-Lag+ 部分反作弊敏感。
- 撤销：改回关。
- 执行：AMD Software → 图形 → Radeon Anti-Lag → 开。

### E3 帧率目标控制（AMD）
- 效果：中
- 作用：限制帧率到略低于刷新率，配合 FreeSync。
- 适用：有 FreeSync。
- 风险：浪费性能。
- 撤销：改回关。
- 执行：AMD Software → 图形 → 帧率目标控制 → 刷新率 - 3~5。

### E4 关闭 Radeon Chill（AMD）
- 效果：中
- 作用：Chill 会压帧省电。
- 适用：竞技/插电游戏。
- 风险：功耗/发热略增。
- 撤销：重新打开。
- 执行：AMD Software → 图形 → Radeon Chill → 关。

### E5 开启 FreeSync（AMD）
- 效果：依场景
- 作用：消除撕裂。
- 适用：FreeSync 显示器。
- 风险：基本无。
- 撤销：关闭。
- 执行：AMD Software → 显示 → AMD FreeSync → 开。

### E6 定向清理 AMD 着色器缓存
- 效果：依场景
- 作用：驱动升级后持续卡顿可尝试。
- 适用：升级驱动后异常。
- 风险：首次重编译更卡。
- 撤销：无；自动重建。
- 执行：AMD Software → 显卡 → 高级 → 着色器缓存 → 清除；或手动删除对应缓存目录。

### E7 Intel Arc / 核显低延迟
- 效果：中
- 作用：降低输入延迟。
- 适用：Intel Arc / 核显用户。
- 风险：基本无。
- 撤销：关闭。
- 执行：Intel Graphics Software / Arc Control → 游戏/性能 → 低延迟 → 开。

## F 启动 / 后台

### F1 禁用不必要的开机启动项
- 效果：中
- 作用：减少进桌面后托盘程序占用。
- 适用：启动项多、内存小。
- 风险：程序不再自启。
- 撤销：任务管理器重新启用。
- 执行：任务管理器 → 启动应用 → 右键禁用（只动用户点名的第三方软件）。

### F2 游戏时退出 Discord / Overwolf / 浏览器
- 效果：中
- 作用：释放 CPU/GPU/网络资源。
- 适用：后台 overlay 多。
- 风险：再打开即可。
- 撤销：重新打开。
- 执行：手动退出，或各软件设置里关闭 overlay。

### F3 暂停 OneDrive 同步
- 效果：中
- 作用：避免游戏时磁盘/网络突发占用。
- 适用：OneDrive 常同步。
- 风险：恢复同步即可。
- 撤销：恢复同步。
- 执行：任务栏 OneDrive → 暂停同步（选 2/8/24 小时）。

### F4 关闭小组件 / 搜索高亮 / Copilot / Teams 自启
- 效果：低
- 作用：减少后台网络/CPU 小占用。
- 适用：低配机。
- 风险：功能消失。
- 撤销：设置里重新打开。
- 执行：
  - 设置 → 个性化 → 任务栏 → 小组件 → 关；
  - 设置 → 隐私和安全性 → 搜索权限 → 搜索高亮 → 关；
  - Copilot、Teams（消费者版）自启在任务管理器“启动”里禁用。

### F5 真重启（不是关机）
- 效果：中
- 作用：快速启动下“关机再开”不清内核会话，只有重启才算真重启；同时可检查是否有挂起的 Windows 更新。
- 适用：开机慢、越用越卡、很久没重启。
- 风险：无。
- 撤销：无。
- 执行：开始 → 电源 → 重启；脚本可查 `LastBootUpTime` 和 pending reboot 状态。

### F6 计划任务 / 第三方服务自启清点
- 效果：中 / 高
- 作用：Adobe、Google、OEM 更新器等计划任务和非微软服务是开机慢 + 后台高的重灾区。
- 适用：开机慢、后台占用高。
- 风险：禁用必要任务可能影响软件更新。
- 撤销：重新启用任务/服务。
- 执行：任务管理器 → 启动 → 影响排序 → 用户勾选禁用；`taskschd.msc` 或 `msconfig`（勾“隐藏所有 Microsoft 服务”）→ 只动用户点名的第三方项。

### F7 OneDrive 根治（取消链接 / 关自启 / 按需文件）
- 效果：中 / 高
- 作用：F3 只是暂停 2/8/24 小时；本项是彻底停止自启或取消链接，长期不再偷占磁盘/网络。
- 适用：不用 OneDrive 或想彻底停用。
- 风险：云端文件不再自动同步，需手动备份。
- 撤销：重新登录 OneDrive / 打开自启。
- 执行：任务栏 OneDrive → 设置 → 账户 → 取消链接此电脑；或任务管理器启动项禁用 OneDrive；文件资源管理器 → OneDrive → 设置 → 文件按需。

### F8 关闭浏览器后台运行
- 效果：中
- 作用：Edge 启动加速 + “关闭后继续运行后台扩展”、Chrome 后台模式是普通用户后台占用的最大单一来源之一。
- 适用：Edge / Chrome 常驻后台。
- 风险：浏览器启动略慢。
- 撤销：重新打开。
- 执行：
  - Edge：设置 → 系统和性能 → 关闭“启动增强”和“关闭后继续运行后台扩展”；
  - Chrome：设置 → 系统 → 关闭“关闭 Google Chrome 后继续运行后台应用”。

### F9 内存大户定位（vmmem / WSL / Docker / 浏览器）
- 效果：中 / 高
- 作用：任务管理器按内存排序找真凶；vmmem / WSL / Docker 是开发机内存满的常见元凶。
- 适用：内存长期 >80%、卡顿、vmmem 占用高。
- 风险：关闭 WSL/Docker 会中断开发环境。
- 撤销：重启 WSL/Docker。
- 执行：任务管理器 → 按内存排序；`wsl --shutdown`（不用 WSL 时）；Docker 退出；浏览器标签页休眠。

## H 网络设备层（不改注册表）

### H1 网卡取消“允许计算机关闭以节约电源”
- 效果：中（网游延迟尖峰）
- 作用：防止网卡睡眠导致延迟尖峰。
- 适用：网游、Wi-Fi。
- 风险：待机耗电略增。
- 撤销：重新勾选。
- 执行：设备管理器 → 网络适配器 → 本机网卡 → 电源管理 → 取消勾选。

### H2 关闭 EEE / Green Ethernet
- 效果：中
- 作用：减少低功耗切换导致的网络抖动。
- 适用：有线网游。
- 风险：待机耗电略增。
- 撤销：改回原值。
- 执行：设备管理器 → 网卡 → 高级 → Energy Efficient Ethernet / Green Ethernet → 禁用。

### H3 Wi-Fi 节电设为最高性能
- 效果：中
- 作用：防止 Wi-Fi 省电模式导致延迟尖峰。
- 适用：无线网游。
- 风险：耗电略增。
- 撤销：改回。
- 执行：设置 → 网络和 Internet → Wi-Fi → 硬件属性 → 节电模式 → 最高性能（可能需设备支持）。

### H4 有线优先 / 设置接口跃点
- 效果：中
- 作用：让有线网卡优先于 Wi-Fi。
- 适用：同时有线和 Wi-Fi。
- 风险：改错别名会报错；跃点设错影响路由。
- 撤销：将 `InterfaceMetric` 改回记录的原值，或 `-AutomaticMetric Enabled`。
- 执行：
  1. `Get-NetAdapter | Select Name` 找到实际有线网卡名（中文系统可能是“以太网”）。
  2. 记录原值：`Get-NetIPInterface -InterfaceAlias '<实际名称>' -AddressFamily IPv4 | Select InterfaceAlias, InterfaceMetric`
  3. 执行：`Set-NetIPInterface -InterfaceAlias '<实际名称>' -InterfaceMetric 10`（需管理员，命令项）。

### H5 DNS 改为公共 DNS（仅解决可达性，不提升 FPS / 不降游戏延迟）
- 效果：非性能（可达性）
- 作用：部分 DNS 解析更快/更稳定；对游戏内 ping、帧数无影响。
- 适用：网页/下载慢、解析失败。
- 风险：个别服务访问异常。
- 撤销：改回自动获取。
- 执行：网络适配器 → IPv4 → DNS → 手动（国内推荐 223.5.5.5 / 119.29.29.29；海外可选 8.8.8.8 / 1.1.1.1）。

## I 安全清理

**本节项不提升 FPS**，只解决卡顿、加载、空间不足；只在对应症状/空间不足时做，不做例行保养。

### I1 清理 %TEMP% 和 Windows Temp
- 效果：低 / 中（空间）
- 作用：删除用户和系统临时文件。
- 适用：C 盘紧张。
- 风险：正在运行的程序可能锁住部分文件；C:\Windows\Temp 需管理员。
- 撤销：无需；丢失的临时文件由程序重建。
- 执行（仅删文件，保留目录；命令项）：
  ```powershell
  if (Test-Path $env:TEMP) { Get-ChildItem $env:TEMP -File -Recurse -ErrorAction SilentlyContinue | Remove-Item -Force -ErrorAction SilentlyContinue }
  if (Test-Path 'C:\Windows\Temp') { Get-ChildItem 'C:\Windows\Temp' -File -Recurse -ErrorAction SilentlyContinue | Remove-Item -Force -ErrorAction SilentlyContinue }
  ```

### I2 清理传递优化缓存
- 效果：低
- 作用：删除 Windows 更新分发缓存。
- 适用：C 盘紧张。
- 风险：下次更新可能重新下载。
- 撤销：无。
- 执行：设置 → 系统 → 存储 → 临时文件 → 传递优化文件 → 删除文件。

### I3 清理缩略图缓存
- 效果：低
- 作用：重建缩略图，可能缓解文件资源管理器卡顿。
- 适用：文件浏览卡。
- 风险：暂时看不到缩略图。
- 撤销：自动重建。
- 执行（命令项；**会重启资源管理器，任务栏消失几秒属正常**）：
  ```powershell
  Stop-Process -Name explorer -Force -ErrorAction SilentlyContinue
  Get-ChildItem "$env:LOCALAPPDATA\Microsoft\Windows\Explorer\thumbcache_*.db" -ErrorAction SilentlyContinue | Remove-Item -Force -ErrorAction SilentlyContinue
  Start-Process explorer
  ```

### I4 清空回收站
- 效果：低
- 作用：释放空间。
- 适用：C 盘紧张。
- 风险：彻底删除；恢复需专业工具。
- 撤销：无。
- 执行：清空回收站。

### I5 清理 Windows.old
- 效果：中（空间，升级后 10-20 GB）
- 作用：删除旧系统备份。
- 适用：C 盘非常紧张且升级已超过 10 天。
- 风险：无法回退旧版本 Windows。
- 撤销：无。
- 执行：`cleanmgr /sageset:1` 选择“以前的 Windows 安装”；或磁盘清理 → 以前的 Windows 安装。

### I6 定向清理着色器缓存
- 效果：依场景
- 作用：驱动升级后持续卡顿可排除缓存损坏。
- 适用：升级驱动后异常。
- 风险：首次进游戏重编译更卡。
- 撤销：无；自动重建。
- 执行（关闭游戏后，仅删文件保留目录；命令项；与 D8 重叠，二选一即可）：
  ```powershell
  $paths = @(
    "$env:LOCALAPPDATA\NVIDIA\DXCache",
    "$env:LOCALAPPDATA\NVIDIA\GLCache",
    "$env:LOCALAPPDATA\NVIDIA\ComputeCache",
    "$env:LOCALAPPDATA\D3DSCache"
  )
  foreach ($p in $paths) { if (Test-Path $p) { Get-ChildItem $p -File -Recurse -ErrorAction SilentlyContinue | Remove-Item -Force -ErrorAction SilentlyContinue } }
  ```

### I7 卸载用户点名不用的软件
- 效果：依场景
- 作用：减少后台/自启/广告。
- 适用：用户明确不需要的软件。
- 风险：卸载不可逆。
- 撤销：重装。
- 执行：设置 → 应用 → 安装的应用 → 卸载用户点名的软件。

### I8 启用存储感知自动清理
- 效果：低
- 作用：定时清理临时文件。
- 适用：懒得手动维护。
- 风险：自动删临时文件；**设置里确认“下载文件夹清理 = 从不”**，否则可能误删下载内容。
- 撤销：设置里关闭。
- 执行：设置 → 系统 → 存储 → 存储感知 → 开 → 配置清理计划（下载文件夹 = 从不）。

### I9 DISM 更新残留清理
- 效果：中（空间）
- 作用：清理 Windows Update 残留组件，通常能释放数 GB。
- 适用：C 盘紧张。
- 风险：无法回退某些更新（通常无影响）。
- 撤销：无需。
- 执行（管理员，命令项）：`Dism.exe /online /Cleanup-Image /StartComponentCleanup`

### I10 TRIM 检查 + HDD 碎片整理
- 效果：中（I/O）
- 作用：SSD 确认 TRIM 开启；HDD 定期碎片整理可减少读取卡顿。
- 适用：HDD 游戏加载慢；SSD 需确认 TRIM。
- 风险：对 SSD 做传统碎片整理会磨损，只保留 TRIM。
- 撤销：无需。
- 执行（`Optimize-Volume` 需管理员，命令项）：
  - `fsutil behavior query DisableDeleteNotify` 返回 0 = TRIM 已开（只读查询，不需授权）；
  - HDD：`dfrgui` 或 `Optimize-Volume -DriveLetter D -Defrag`；
  - SSD：`Optimize-Volume -DriveLetter C -ReTrim`。

### I11 Windows Search 降负
- 效果：中（I/O）
- 作用：索引服务在后台持续扫文件，磁盘 100% 时是经典元凶。
- 适用：磁盘长期 100%、SearchIndexer 占用高。
- 风险：搜索变慢；停服务为末选。
- 撤销：恢复“增强”模式或重启服务。
- 执行（用户手动，模型不代执行）：
  - 设置 → 隐私和安全性 → 搜索 Windows → 经典；
  - 排除游戏盘 / 大目录；
  - 仍异常时 `services.msc` → Windows Search → 手动/禁用（需明确告知搜索变慢）。

## J 游戏内设置

### J1 渲染比例 / DLSS / FSR / XeSS 设为质量或性能
- 效果：高（GPU 限）
- 作用：降低渲染分辨率再超分重建，省算力。
- 适用：帧数低、GPU 吃满。
- 风险：画质下降。
- 撤销：改回原设置。
- 执行：根据显卡选可用技术：
  - NVIDIA RTX 20/30/40/50 系 → DLSS 质量/平衡/性能
  - AMD RX 6000+ → FSR 质量/平衡/性能
  - Intel Arc → XeSS
  - 老卡/不支持超分 → 直接调渲染比例 70–90%
- 注意：不要对 GTX 10 系、核显、老 A 卡推荐 DLSS；它们不支持。

### J2 纹理质量匹配显存
- 效果：高（爆显存时）
- 作用：防止越玩越卡、爆显存。
- 适用：专用显存顶满。
- 风险：画面变糊。
- 撤销：改回原档。
- 执行：游戏内 → 纹理/材质 → 降一档。

### J3 关闭光追 / 阴影 / 反射
- 效果：高（GPU 限）
- 作用：光追和高级反射最吃 GPU。
- 适用：3A 帧数低。
- 风险：画面变差。
- 撤销：改回打开。
- 执行：游戏内 → 光线追踪/阴影/反射 → 关或低。

### J4 关闭垂直同步 + 设置帧上限
- 效果：中
- 作用：避免 V-Sync 锁帧或撕裂；有 VRR 时锁到刷新率 -3~5 可换取帧时间平顺。
- 适用：帧数高于刷新率，且显示器支持 G-Sync/FreeSync。
- 风险：可能撕裂；无 VRR 屏直接锁低 3~5 帧会白丢帧。
- 撤销：重新打开 V-Sync 或改回无限制。
- 执行：游戏内 → 垂直同步 → 关；帧率限制 → 刷新率 - 3~5（仅 VRR）。

### J5 Reflex / Anti-Lag
- 效果：中（竞技游戏）
- 作用：降低输入延迟。
- 适用：支持 Reflex 的游戏。
- 风险：基本无。
- 撤销：关闭。
- 执行：游戏内 → NVIDIA Reflex → 开 / On+Boost；AMD → Anti-Lag → 开。

### J6 独占全屏 vs 无边框
- 效果：依场景
- 作用：Win11 开启“窗口化游戏优化”（B8）后，无边框通常已拿到近似独占的延迟；独占全屏仅 DX9/老引擎或异常时再试。
- 适用：跟手差、切屏需求。
- 风险：独占模式可能切屏黑屏/崩溃。
- 撤销：改回无边框。
- 执行：优先无边框 + B8；异常时游戏内 → 显示模式 → 独占全屏 + B7。

### J7 禁用游戏内覆盖层
- 效果：中
- 作用：减少 GeForce Experience / Steam / Discord overlay 占用。
- 适用：后台 overlay 多。
- 风险：失去 overlay 功能。
- 撤销：各软件设置里打开。
- 执行：NVIDIA App / Steam / Discord / Xbox 设置里关闭 overlay。

### J8 帧生成（通用路径）
- 效果：高（支持时）
- 作用：AI/算法插帧，可显著提升显示帧数；FSR3 FG 不限显卡品牌，RTX 20/30 也能用；AFMF 覆盖 RX 6000+；NVIDIA Smooth Motion 是驱动级、RTX 50/40 可用；无原生支持时用 Lossless Scaling（LSFG，Steam 付费）可对几乎任意游戏插帧。
- 适用：原生帧 ≥30 但想更流畅；支持 DLSS FG / FSR3 FG / AFMF / LSFG 的游戏或驱动。
- 风险：输入延迟增加、UI/高速运动可能有鬼影；原生帧太低时效果差。
- 撤销：游戏内 / 驱动里关闭。
- 执行：游戏内 → DLSS 帧生成 / FSR3 帧生成 / AFMF；或 NVIDIA App → Smooth Motion；或 Steam → Lossless Scaling。

### J9 渲染 API 切换（DX11 / DX12 / Vulkan）
- 效果：依场景（可高可低）
- 作用：不同 API 对不同显卡/CPU 表现不同；Fortnite 还有 Performance Mode 低配渲染管。
- 适用：帧数异常低、特定 API 下卡顿。
- 风险：切换后画质/稳定性变化。
- 撤销：切回原 API。
- 执行：游戏内 → 图形 → API → 切 DX11/DX12/Vulkan；或启动参数 `-dx11` / `-vulkan` 等。

### J10 游戏配置文件编辑（.ini / .cfg / .xml）
- 效果：依场景
- 作用：改隐藏画质/性能参数，突破菜单上限。
- 适用：菜单没有想调的项；需按游戏联网搜教程。
- 风险：改坏导致崩溃；**必须先备份原文件**；不改反作弊、可执行文件、存档相关字段。**强反作弊网游（ACE/EAC/BE/Vanguard）慎用**——改配置/加参数被判异常的风险高于单机，必要时先联网查该游戏社区确认安全。
- 撤销：恢复备份。
- 执行：复制原文件 → 修改 → 验证启动；**配置文件位置因游戏而异**，先联网搜"游戏名 + config / ini 位置"定位，常见路径如 `文档\My Games\<Game>`、`%LOCALAPPDATA%\<Game>\Saved\Config`。

## K 驱动 / 硬件

### K1 更新或回退 GPU 驱动
- 效果：高 / 依场景
- 作用：修复 bug 或提升新游戏性能；回退可解决突发卡顿。
- 适用：驱动异常、新游戏发布、升级驱动后变卡。
- 风险：新驱动可能反向优化；**Game Ready 追新游戏首发优化，Studio 更稳定适合创作**；优先用官方安装器“清洁安装”，**不要常规用 DDU**（仅驱动损坏且用户书面点名后，自行安全模式执行）。
- 撤销：设备管理器回退驱动或还原点。
- 执行：NVIDIA App / AMD Adrenalin / Intel Graphics Software；回退用设备管理器 → 属性 → 驱动程序 → 回退。

### K2 开启 XMP / EXPO / DOCP
- 效果：高（内存频率未跑满时）
- 作用：让内存跑到标称频率。
- 适用：`ConfiguredClockSpeed` 明显低于 `Speed`。
- 风险：不稳定会掉帧/闪退/蓝屏；需进 BIOS；**若已开 XMP 仍报错，先改回 Auto 排障**；AM5 早期 AGESA + EXPO 有 SOC 电压案例，确认 BIOS 版本较新。
- 撤销：BIOS 改回 Auto。
- 执行：开机进 BIOS → 内存 XMP/EXPO/DOCP → 开 → 跑一轮内存压力测试。

### K3 确认双通道内存
- 效果：高（Ryzen / 核显尤其明显）
- 作用：双通道带宽翻倍。
- 适用：只有一根内存条。
- 风险：无；需加内存条。
- 撤销：拔出新增内存。
- 执行：任务管理器/CPU-Z 看通道数；插两根同规格内存。

### K4 散热清灰 / 换硅脂
- 效果：高（温度限频时）
- 作用：防止 CPU/GPU 因高温降频。
- 适用：温度高、风扇狂转。
- 风险：拆机风险；动手能力不足找售后。
- 撤销：无。
- 执行：拆机清灰、换硅脂、检查风扇转速。

### K5 使用有线网络
- 效果：中 / 高
- 作用：Wi-Fi 波动大，有线更稳定。
- 适用：竞技网游。
- 风险：无。
- 撤销：拔网线。
- 执行：插网线。

### K6 游戏/系统盘使用 SSD / NVMe
- 效果：高（机械硬盘或慢 SSD 场景）
- 作用：减少加载卡顿、贴图流送延迟，DirectStorage 游戏更受益。
- 适用：游戏装在机械硬盘或老旧 SATA SSD。
- 风险：需购买/迁移数据；迁移前备份。
- 撤销：无。
- 执行：把系统和常玩游戏迁移到 NVMe SSD；开启主板 BIOS 中 M.2 NVMe 相关设置。

### K7 开启 Resizable BAR / Smart Access Memory / Above 4G Decoding
- 效果：高（支持游戏 +5~15%，Intel Arc 无 ReBAR 损失更大）
- 作用：让 CPU 直接访问全部显存，提升贴图/几何数据吞吐。
- 适用：RTX 30+/RX 6000+/Intel Arc；BIOS 支持；个别游戏负优化可关。
- 风险：需进 BIOS 改 Above 4G Decoding + Re-Size BAR；CSM 须关闭、系统需 UEFI 启动。
- 撤销：BIOS 里关闭 Above 4G / ReBAR。
- 执行：NVIDIA 控制面板 → 系统信息 → Resizable BAR = 是；`nvidia-smi -q` 也可读；BIOS → PCI/Advanced 设置 → Above 4G Decoding + Re-Size BAR → 开。**不同主板叫法和位置不同**（ASUS/Gigabyte/MSI 菜单层级不一，AMD 平台可能叫 SAM），找不到按主板型号联网搜。

### K8 显示器物理接独显 + 游戏本 MUX / 独显直连 + 确认插电
- 效果：高（接错口损失可达一半以上）
- 作用：台式机线插在主板口会走核显输出；游戏本 MUX/Advanced Optimus 独显直连可提升 5~15% 且降延迟；不插电进省电模式是最常见“突然变卡”原因。
- 适用：台式机显示器插主板口；游戏本有 MUX/Advanced Optimus；笔记本用户。
- 风险：切换独显直连需重启；笔记本续航变短。
- 撤销：改回混合输出 / 插回核显口。
- 执行：台式机把 HDMI/DP 插到显卡输出；游戏本在 NVIDIA 控制面板 / Armoury Crate / Lenovo Vantage 等里开“独显直连 / MUX”；确认笔记本插电源玩。

### K9 PCIe 链路 / 供电检查
- 效果：中 / 高（异常时）
- 作用：显卡插在 x4 槽、延长线 Gen 不匹配、8pin 一拖二、低功率适配器都会造成降速或功耗墙节流。
- 适用：`nvidia-smi` 显示 link width/gen 降速、throttle reason = Pwr。**先查该卡原生接口规格再判断是否降速**——RTX 4060/4050 及许多移动版/中低端卡原生就是 x8，x8 ≠ 降速。
- 风险：需拆机/进 BIOS；PSU 功率不足需换电源。
- 撤销：换回原槽/线。
- 执行：确认显卡插第一条 x16 槽；检查延长线版本；8pin 独立线不并接；12VHPWR 插到底；笔记本用原装大功率适配器。

### K10 风扇曲线 / 散热环境
- 效果：中（温度限频时）
- 作用：温度正常但热点/显存结温高、风扇曲线保守、机箱闷罐、笔记本垫高，都是不动手拆机就能做的项。
- 适用：温度高、风扇不转、机箱进风差。
- 风险：风扇曲线过激会吵；硅脂涂多溢出。
- 撤销：恢复默认曲线。
- 执行：OEM 软件 / MSI Afterburner / BIOS 调风扇曲线；笔记本垫高；清进风口灰尘；`nvidia-smi` 读 `temperature.memory` 看 GDDR6X 结温。

## M 低配置 / 已最低画质仍卡（榨干模式）

当游戏已经最低画质、分辨率已经不满足目标帧数时，优先用下面这些项。如果这些都做完还是不够，就只能升级硬件。

### M1 降低渲染分辨率 / DLSS 超性能 / FSR 超性能
- 效果：高
- 作用：把实际渲染像素数压到最低，用超分技术拉回一点清晰度。
- 适用：30–60 帧目标的中低端卡。
- 风险：画面明显变糊。
- 撤销：游戏内改回原档。
- 执行：游戏内 渲染比例 50–70%；或显卡支持的超分技术：
  - NVIDIA RTX 20/30/40/50 系 → DLSS Performance / Ultra Performance
  - AMD RX 6000+ / Intel Arc → FSR Performance / Ultra Performance 或 XeSS
  - 老卡/不支持超分 → 只能降渲染比例或输出分辨率（M4）
- 注意：模型必须根据用户显卡选择对应技术，不要对 GTX 10 系、核显推荐 DLSS。

### M2 开启动态分辨率
- 效果：高（场景复杂时）
- 作用：爆炸、烟雾、人多时自动降分辨率保帧。
- 适用：场景波动大，平时够，复杂场景掉帧。
- 风险：画面清晰度波动。
- 撤销：游戏内关闭。
- 执行：游戏内 动态分辨率 / Adaptive Resolution → 开，目标帧数设目标值。

### M3 开启帧生成（Frame Generation）
- 效果：高（支持时）
- 作用：DLSS 3 / FSR 3 / AFMF / LSFG 用 AI/算法插帧，可显著提升显示帧数；FSR3 FG 不限显卡品牌。（与 J8 同一技术，本项特指榨干场景；已推过 J8 就别重复列。）
- 适用：RTX 40+/RX 6000+ 或支持 AFMF/LSFG 的场景；原生帧能稳 30+。
- 风险：输入延迟增加；原生帧低于 30 时画面会碎/鬼影。
- 撤销：游戏内关闭帧生成。
- 执行：游戏内 DLSS Frame Generation / FSR3 Frame Generation / AMD AFMF 打开；无原生支持时考虑 Lossless Scaling。

### M4 降低输出分辨率
- 效果：高（最直接的减负载手段）
- 作用：直接减少 GPU 像素负载。
- 适用：显卡远低于游戏推荐配置。
- 风险：画面明显变糊。
- 撤销：游戏内改回原分辨率。
- 执行：显示器原生 1080p 可设 900p/720p；窗口化 1280×720；低端核显可设 800×600。

### M5 关闭引擎级特效
- 效果：高（UE5/新引擎）
- 作用：Lumen、Nanite、虚拟阴影、体积雾、屏幕空间反射、环境光遮蔽都很吃资源。
- 适用：新 3A / UE5 游戏在中低端卡上。
- 风险：画面变平。
- 撤销：游戏内重新打开。
- 执行：游戏内 Lumen → 关闭 / Nanite → 关闭 / 虚拟阴影 → 关闭 / 体积雾、反射、AO 全部最低或关闭。

### M6 降低视野距离 / 后期处理 / 抗锯齿
- 效果：中
- 作用：CPU/GPU 渲染距离和后期特效减少。
- 适用：开放世界、大战场。
- 风险：远处贴图加载近，画面锯齿多。
- 撤销：游戏内改回。
- 执行：视野距离低、后期处理低、抗锯齿 FXAA/TAA 级别最低、关闭运动模糊。

### M7 设置游戏进程优先级为“高”
- 效果：低 / 依场景（收益通常接近零，仅后台极多时可试）
- 作用：让 CPU 优先调度游戏进程，减少后台抢走时间片。
- 适用：后台多、低端 CPU。
- 风险：不要选“实时”，否则可能卡死系统；设置不持久，重启游戏即失效。
- 撤销：任务管理器改回“正常”。
- 执行：游戏运行后，任务管理器 → 详细信息 → 游戏 exe → 右键设置优先级 → 高；若要注册表/IFEO/工具持久化，走 L5 书面授权。

### M8 设置游戏进程亲和（强制 P 核 / 禁用 E 核）
- 效果：中 / 依场景
- 作用：老游戏/单核敏感游戏只吃 P 核，避免被分到 E 核。
- 适用：Intel 12 代以上、游戏明显一核或几核吃满、E 核频率低导致掉帧。
- 风险：现代多核游戏可能反而更卡；每次启动游戏都要重新设。
- 撤销：任务管理器 → 详细信息 → 游戏 exe → 设置相关性 → 全选。
- 执行：任务管理器 → 详细信息 → 游戏 exe → 设置相关性 → 只勾选 P 核（P 核编号因 CPU 而异，任务管理器里看“性能核”或按核心数判断；不确定就跳过）。
- 注意：本项是**任务管理器按次设置**，属低风险 UI 项；若要注册表/第三方工具持久化，走 L5 书面授权。

### M9 关闭游戏内覆盖层（Steam、Discord、NVIDIA、Xbox）
- 效果：低 / 中
- 作用：减少每帧额外的绘制/录屏开销。
- 适用：低端机，帧数紧。
- 风险：无法截图/录屏/看帧数。
- 撤销：各自软件里打开。
- 执行：Steam 设置关闭覆盖；Discord 设置关闭覆盖；NVIDIA App/GeForce Experience 关闭覆盖；Xbox Game Bar 关闭。

### M10 用启动参数强制 DX11 / Vulkan
- 效果：中 / 依场景
- 作用：部分游戏 DX12 开销大，DX11 更流畅。
- 适用：老卡、核显、DX12 表现差的游戏。
- 风险：可能打不开或缺少功能；**强反作弊网游慎用**，可能被反作弊判异常。
- 撤销：删除启动参数。
- 执行：Steam/WeGame/Epic 启动项加 `-dx11`、`-vulkan` 等；具体参数需搜该游戏。

## L 高阶 / 风险项（仅说明，不主动执行）

### L1 关闭 VBS / HVCI / 内存完整性
- 效果：依场景（现代 CPU + Win11 实测普遍 0–5%，非"高"）
- 作用：减少虚拟化安全开销。
- 风险：反作弊可能报错，安全性下降。
- 前提：用户书面点名 + 检索反作弊官方不要求 + 完整找回路径。
- 撤销：设置 → Windows 安全中心 → 设备安全性 → 内核隔离 → 内存完整性 → 开。

### L2 关闭 SysMain / Superfetch（仅说明，不执行）
- 效果：依场景（HDD + 磁盘 100% 时可能有效；SSD 通常无感或略负）
- 作用：减少后台预读。
- 前提：资源监视器显示 SysMain 高占用 + HDD + 磁盘 100% + 用户明确理解风险。
- 风险：机械硬盘系统可能更卡；固态一般无感。
- 说明：模型不代执行；满足前提时指导用户在 `services.msc` → SysMain → 禁用，并给恢复命令 `sc config SysMain start=auto` + `net start SysMain`。

### L3 调整 MSI Mode / 中断亲和
- 效果：依场景
- 作用：降低 DPC 延迟。
- 风险：可能导致系统不稳定、蓝屏。
- 前提：有 LatencyMon 证据 + .reg 备份 + 用户书面点名。
- 撤销：恢复 .reg 备份或改回原值。

### L4 调整 TdrDelay / TdrDdiDelay
- 效果：依场景
- 作用：防止 GPU 驱动重置导致卡顿。
- 风险：可能掩盖硬件/驱动问题。
- 前提：有 TDR 4101 事件 + .reg 备份 + 用户书面点名。
- 撤销：删除新增键值或恢复 .reg 备份。

### L5 进程亲和持久化（注册表 / IFEO / 第三方工具）
- 效果：依场景
- 作用：把进程亲和/优先级写进注册表或工具，每次启动自动生效。
- 风险：可能降低多核利用率；改坏可能导致游戏无法启动。
- 前提：明确某个游戏问题 + 任务管理器按次验证有效 + 用户书面点名；任务管理器按次设置属低风险 UI，不需要本项。
- 撤销：删除 IFEO 键值 / 卸载工具。

### L6 超频 / 降压 / 功耗墙解锁（仅说明，不执行）
- 效果：依场景
- 作用：说明已有超频/降压/功耗墙解锁的风险；不稳定 OC/XMP 会导致 WHEA、闪退、帧时间毛刺。
- 风险：超频不稳 = 掉帧、蓝屏、硬件损伤。
- 前提：检测到 WHEA 事件或用户承认有 OC 时，排障第一步 = 恢复默认；模型不代执行任何超频/解锁操作。

## 附录 · 术语白话表（对小白解释时用）

- HAGS → Windows 图形设置里的显卡调度开关
- VBS / HVCI → 内核隔离里的内存完整性（安全功能，默认别开）
- DPC → 驱动响应延迟
- 渲染比例 → 游戏内按百分比渲染再放大
- 1% low / 0.1% low → 最差 1% / 0.1% 时间的帧数，越低越卡
- 帧时间毛刺 → 某一帧突然特别慢，体感"顿一下"
- GUID → 电源计划编号，脚本内部用，不用记
- 独占全屏 / 无边框 → 游戏占满屏幕的两种模式
- 帧生成 → AI/算法插出来的额外帧，不是真实渲染帧
- ReBAR → 让 CPU 直接访问全部显存的 BIOS 开关
