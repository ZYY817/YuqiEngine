核心调度

关闭核心停泊与降频策略，保持满频运行

0 / 3 启用
  • 禁用核心停泊（Core Parking）中等推荐

    将所有 P-Core 强制保持唤醒，减少调度延迟，避免在高速场景下唤醒核心带来的卡顿

  • 启用 Processor Boost中等

    允许 CPU 主动加速到睿频频率，单核负载场景下更易达到峰值频率

  • 禁用 Power Throttling安全推荐

    PowerThrottlingOff=1，确保前台进程不被自动限频，功耗略增

计时器与时钟

提升计时器精度，降低输入和音频延迟

0 / 4 启用
  • 锁定 0.5 ms 计时器中等

    调用 NtSetTimerResolution 请求 0.5 ms 计时器精度，降低输入和音频延迟，略增 CPU 功耗

  • 禁用动态时钟（Dynamic Tick）高风险需重启

    写入 bcdedit /set disabledynamictick yes，关闭无滴答内核，部分场景下可降低 DPC 抖动

  • 禁用 HPET高风险需重启

    写入 bcdedit /set useplatformclock no，关闭高精度事件计时器，AMD 推荐 / Intel 谨慎

  • 启用平台计时器高风险AMD 推荐

    useplatformtick=Yes，使用 TSC 替代 HPET，AMD CPU 推荐，可解决随机抽帧
